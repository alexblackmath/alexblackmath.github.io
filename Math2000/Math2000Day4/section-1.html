    Section 1 Exercises and Solutions

    Checkpoint 1.1.

    Consider the following linear system:
    \begin{align*} x_{1} + x_{2} + x_{3} + x_{4} \amp = 4\\ 3x_{1} + 6x_{2} + 6x_{3} + 3x_{4} \amp = 123 \end{align*}
    🔗

    (a)

    The first equation says that \(x_{1} = 4 - x_{2} - x_{3} - x_{4}\text{.}\) Plug \(4 - x_{2} - x_{3} - x_{4}\) into the second equation for \(x_{1}\) and see what you get.
    🔗
    Solution.
    You should find the new equation \(3x_{2} + 3x_{3} = 111\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Subtract \(3\) times the first equation from the second equation.
    🔗
    Solution.
    You should find the new equation \(3x_{2} + 3x_{3} = 111\text{.}\)
    🔗
    🔗
    🔗

    (c)

    How do your answers for parts (a) and (b) compare?
    🔗
    Solution.
    They are equal.
    🔗
    🔗
    🔗
    🔗
    A diagonal matrix is a square matrix such that every entry other than the diagonal is \(0\text{.}\) If the coefficient matrix is diagonal, the linear system generally is easier to solve.
    🔗

    Checkpoint 1.2.

    Consider the linear system:
    \begin{align*} 3x \amp = 0\\ 2y \amp = 8\\ 5z \amp = 10 \end{align*}
    🔗

    (a)

    Write the coefficient matrix of the system.
    🔗
    Solution.
    The coefficient matrix is
    \begin{equation*} \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 5 \end{pmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (b)

    Write the augmented matrix of the system.
    🔗
    Solution.
    The augmented matrix is
    \begin{equation*} \begin{pmatrix} 3 \amp 0 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \amp 8 \\ 0 \amp 0 \amp 5 \amp 10 \end{pmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (c)

    Is the system consistent of inconsistent? If the system is consistent, give a solution. Is the solution unique?
    🔗
    Solution.
    The system is consistent, since it has a solution \(x = 0\text{,}\) \(y = 4\text{,}\) and \(z = 5\text{.}\) The solution is unique.
    🔗
    🔗
    🔗
    🔗
    An upper triangular matrix is a square matrix such that every entry strictly below the diagonal is \(0\text{.}\)
    🔗

    Checkpoint 1.3.

    Consider the linear system:
    \begin{align*} x + y + z \amp = 3\\ y + z \amp = 2\\ z \amp = 0 \end{align*}
    🔗

    (a)

    Write the coefficient matrix of the system.
    🔗
    Solution.
    The coefficient matrix is
    \begin{equation*} \begin{pmatrix} 1 \amp 1 \amp 1 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (b)

    Write the augmented matrix of the system.
    🔗
    Solution.
    The augmented matrix is
    \begin{equation*} \begin{pmatrix} 1 \amp 1 \amp 1 \amp 3 \\ 0 \amp 1 \amp 1 \amp 2 \\ 0 \amp 0 \amp 1 \amp 0 \end{pmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (c)

    Is the system consistent of inconsistent? If the system is consistent, give a solution. Is the solution unique?
    🔗
    Solution.
    The system is consistent with a unique solution \(z = 0\text{,}\) \(y = 2\text{,}\) and \(x = 1\text{.}\)
