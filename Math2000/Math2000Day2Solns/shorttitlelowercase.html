    Section 1 Exercises

    NOTE: You are not expected to have solved all of these exercises in class. Their sole purpose is to start having you think about the material while I’m there, so we can talk about it together.
    🔗

    Checkpoint 1.1.

    Consider the following system of linear equations in variables \(x_{1}, x_{2}, y_{1}, y_{2}, y_{3}, y_{4}\text{:}\)
    \begin{align*} x_{1} + y_{1} \amp = 1\\ -x_{1} + y_{2} \amp = 0\\ x_{2} + y_{3} \amp = 1\\ -x_{2} + y_{4} \amp = 0 \end{align*}
    🔗

    (a)

    Write down the augmented matrix.
    🔗
    Solution.
    The augmented matrix is
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp 1 \\ -1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 1 \\ 0 \amp -1 \amp 0 \amp 0 \amp 0 \amp 1 \amp 0 \end{pmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (b)

    Put the augmented matrix in reduced row echelon form.
    🔗
    Solution.
    To put it in reduced row echelon form, you first look for the left most column with nonzero entry. That is your first pivot column. Pick a favorite row whose leading entry is in that column. I pick the first row. Then rescale it so the leading entry is \(1\text{.}\) That is already the case, so I don’t do anything. Then for every other row with same leading entry, replace it with the row plus a multiple of the first row that cancels out that entry. Here the only row other than the first with the leading entry in the first column is the second row, so I replace the second row with it plus the first row to get the following:
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 1 \\ 0 \amp -1 \amp 0 \amp 0 \amp 0 \amp 1 \amp 0 \end{pmatrix} \end{equation*}
    🔗
    Now there is a unique row, the first row, with leading entry in the first column, and that entry is equal to \(1\text{.}\) That is what we want, so now we look at all rows with next leftmost leading entry. Here those are rows \(3\) and \(4\text{.}\) I pick my favorite. Here I choose row \(3\text{.}\) You rescale it so its leading entry. Here that is already the case, so we’re golden. Now we take any other row with leading entry in the same column. The only other row like that is row 4. We want to cancel out the entry in that column. To do that we replace it with it plus the suitable scaling of our favorite row, row 3. Here we replace row 4 with row 4 plus row 3.
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp 1 \amp 1 \end{pmatrix} \end{equation*}
    🔗
    Now the second column has a unique nonzero entry equal to \(1\text{.}\) We move that row up to the top using interchange directly below the row with the previous pivot element. This yields the following matrix:
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp 1 \amp 1 \end{pmatrix} \end{equation*}
    🔗
    Now again we look at the next column with earliest leading entry among the remaining rows. That is the third column. We pick our favorite row with leading entry in that column. That is row \(3\text{.}\) Then we replace any other row with a nonzero entry in that column by adding a scalar multiple of row \(3\) to cancel it out. In this case, that row would be row \(1\text{.}\) And to cancel out the third entry in row \(1\text{,}\) I subtract row \(3\text{.}\) This yields the following:
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 0 \amp -1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp 1 \amp 1 \end{pmatrix} \end{equation*}
    🔗
    Now there is a unique nonzero entry in the third column. It is equal to \(1\text{,}\) and it is in the row at the top among the remaining rows to look at. That means we move on to looking at the last row. I look at the leading entry. It is in column \(5\text{.}\) It is equal to \(1\) already, so we don’t need to scale it. There is \(1\) other row with a nonzero entry in that column, which is row \(2\text{.}\) We cancel it out with replacement:
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 0 \amp -1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp 1 \amp 1 \end{pmatrix} \end{equation*}
    🔗
    After all that labor, the resulting matrix is in reduced row echelon form.
    🔗
    🔗
    🔗

    (c)

    What is the dimension of the solution set?
    🔗
    Solution.
    There are four pivot columns, columns \(1, 2, 3,\) and \(5\) corresponding to variables \(x_{1}, x_{2}, y_{1}, y_{3}\text{.}\) Those are our dependent variables. There are three non-pivot columns. Two correspond to independent variables \(y_{2}\) and \(y_{4}\text{.}\) The final column corresponds to constants. Since there are two independent variables, the solution set is two dimensional. The resulting system of equations is
    \begin{align*} x_{1} - y_{2} \amp = 0\\ x_{2} - y_{4} \amp = 0\\ y_{1} + y_{2} \amp = 1\\ y_{3} + y_{4} \amp = 1 \end{align*}
    🔗
    🔗
    🔗

    (d)

    Give an explicit parametrization of the solution set.
    🔗
    Solution.
    Since \(y_{2}\) and \(y_{4}\) are independent variables, to parametrize the solution set, we solve in terms of \(y_{2}\) and \(y_{4}\text{.}\) Then we get
    \begin{align*} x_{1} \amp = y_{2}\\ x_{2} \amp = y_{4}\\ y_{1} \amp = 1-y_{2}\\ y_{3} \amp = 1-y_{4} \end{align*}
    🔗
    Thus, the plane we get if we let \(s = y_{2}\) and \(t = y_{4}\) is
    \begin{equation*} f(s,t) = (s,t,1-s,s,1-t,t). \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Checkpoint 1.2.

    Consider the following matrix:
    \begin{equation*} \begin{pmatrix} 0 \amp 0 \amp 1 \amp 3 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 2 \\ 1 \amp 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    🔗

    (a)

    Put the matrix in reduced row echelon form.
    🔗
    Solution.
    The matrix is very close. We just need to do some interchanging. Reorder so that the last row comes first, then the third row comes second, the first row comes third, and the second row comes last. This yields the following matrix:
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \amp 2 \\ 0 \amp 0 \amp 1 \amp 3 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    🔗
    The resulting matrix is in reduced row echelon form.
    🔗
    🔗
    🔗

    (b)

    Suppose this is the augmented matrix of a linear system. Will that linear system be consistent? Explain why or why not.
    🔗
    Solution.
    Suppose it is the augmented matrix of a linear system. The last column is not a pivot column, so the linear system would be consistent.

    Checkpoint 1.3.

    Consider the following matrix:
    \begin{equation*} \begin{pmatrix} 0 \amp 0 \amp 1 \amp 3 \\ 0 \amp 1 \amp 0 \amp 2 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    🔗
    Suppose this is the coefficient matrix of a linear system. For which right hand sides is it consistent?
    🔗
    Solution.
    The augmented matrix for the system would look like:
    \begin{equation*} \begin{pmatrix} 0 \amp 0 \amp 1 \amp 3 \amp a \\ 0 \amp 1 \amp 0 \amp 2 \amp b \\ 0 \amp 0 \amp 0 \amp 0 \amp c \end{pmatrix} \end{equation*}
    🔗
    I could do like last time in put it in reduced row echelon form. Instead if I write out the equations I get,
    \begin{align*} x_{3} + 3x_{4} \amp = a\\ x_{2} + 2x_{4} \amp = b\\ 0 \amp = c \end{align*}
    🔗
    Then \(c = 0\text{,}\) but \(a\) and \(b\) can be any thing. In particular, \((0,b,a,0)\) is always a solution for any choice of \(a\) and \(b\text{,}\) when \(c = 0\text{.}\)
