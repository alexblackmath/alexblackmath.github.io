    Subsection 1.2 Reminder: From Linear Transformations to Matrices

    Checkpoint 1.1.

    Given a matrix:
    \begin{equation*} A = \begin{bmatrix}1 \amp 2 \amp 3\\4 \amp 5 \amp 6 \\7 \amp 8 \amp 9 \end{bmatrix}\text{,} \end{equation*}
    what do we find when we compute
    \begin{equation*} Ae_{1} = A\begin{bmatrix} 1\\0\\0\end{bmatrix}\text{?} \end{equation*}
    What about \(A e_{2}\) and \(Ae_{3}\text{?}\)
    🔗
    🔗
    This observation extends in general to give us the following result:
    🔗

    Theorem 1.2.

    Given a linear transformation \(T: \mathbb{R}^{n} \to \mathbb{R}^{m}\text{,}\)
    \begin{equation*} T(\vec{x}) = A\vec{x}\text{,} \end{equation*}
    where \(A\) is the \(m \times n\) matrix with columns \(T(e_{1}),\dots,T(e_{n})\text{.}\)
    🔗
    🔗

    Proof.
    Note that
    \begin{equation*} T(\sum_{i=1}^{n} x_{i} e_{i}) = \sum_{i=1}^{n} x_{i} T(e_{i}) = \begin{bmatrix} T(e_{1}) \amp T(e_{2}) \amp \dots \amp T(e_{n})\end{bmatrix}\vec{x} = A \vec{x}\text{.} \end{equation*}
    🔗
    🔗
    But what about for abstract vector spaces?
    🔗
    🔗

    Subsection 1.3 Change of Basis

    Let \(T: U \to V\) be a linear transformation between finite dimensional vector spaces \(U\) and \(V\) of dimension \(n\) and \(m\) respectively. This linear transformation may be defined abstractly, and instead we want to write it down explicitly.
    🔗
    To do this we take a basis \(\vec{u}_{1}, \dots, \vec{u}_{n}\) for \(U\) and \(\vec{v}_{1}, \dots, \vec{v}_{m}\) for \(V\text{.}\) Then there are linear isomorphisms \(P: \mathbb{R}^{n} \to U\) and \(Q: \mathbb{R}^{m} \to V\) given by
    \begin{align*} P(x_{1},\dots, x_{n}) \amp= \sum_{i=1}^{n} x_{i} \vec{u}_{i}\\ Q(y_{1},\dots, y_{m}) \amp= \sum_{j=1}^{m}y_{j}\vec{v}_{j} \end{align*}
    🔗
    Then we can define a linear transformation \(F: \mathbb{R}^{n} \to \mathbb{R}^{m}\) by
    \begin{equation*} F(\vec{x}) = Q^{-1} T P(\vec{x})\text{.} \end{equation*}
    Then \(F\) is represented by a matrix \(A\text{,}\) and we say the matrix \(A\) represents the linear transformation \(T: U \to V\) with respect to the bases \(\vec{u}_{1}, \dots, \vec{u}_{n}\) and \(\vec{v}_{1},\dots,\vec{v}_{m}\text{.}\) Different bases give rise to different matrices.
    🔗
    The core question is: What is the natural basis for us to use?
    🔗
    🔗

    Subsection 1.4 Diagonalization

    We’ll focus on operators and use the same basis for the domain and co-domain, so here \(P = Q\text{.}\)
    🔗

    Definition 1.3.

    An operator \(T\) is diagonalizable over \(\mathbb{R}\) if \(V\) has a basis consisting of real eigenvectors of \(T\text{.}\)
    🔗
    🔗
    We call a basis of eigenvectors an eigenbasis.
    🔗

    Theorem 1.4.

    Let \(T: V \to V\) be an operator, and let \(\mathcal{B}= \{\vec{v}_{1}, \dots, \vec{v}_{n}\}\) be a basis. Then the matrix with respect to \(\mathcal{B}\) representing \(T\) is diagonal with nonzero entries on the diagonal if and only if \(\vec{v}_{1},\dots, \vec{v}_{n}\) is an eigenbasis with nonzero eigenvalues.
    🔗
    🔗

    Proof.
    Let \(A\) be the matrix representing \(T\text{.}\) Then \(A\) is diagonal with nonzero entries on the diagonal if and only if there exist \(\lambda_{1}, \dots, \lambda_{n} \in \mathbb{R} \setminus \{0\}\) such that
    \begin{equation*} Ae_{i} = \lambda_{i} e_{i} \end{equation*}
    for all \(1 \leq i \leq n\text{.}\)
    🔗
    Suppose first that \(A\) is diagonal. Since \(A\) represents \(T\text{,}\) for all \(1 \leq i \leq n\)
    \begin{equation*} \lambda_{i} e_{i} = A(e_{i}) = P^{-1} T P(e_{i}) = P^{-1}T(\vec{v}_{i})\text{.} \end{equation*}
    By applying \(P\) on the left of both sides, we find,
    \begin{equation*} \lambda_{i}\vec{v}_{i} = P(\lambda_{i} e_{i}) = P(P^{-1}(T(\vec{v}_{i}))) = T(\vec{v}_{i})\text{,} \end{equation*}
    so \(\vec{v}_{i}\) is an eigenvector for all \(1 \leq i \leq n\text{.}\) Since \(A\) is diagonal with nonzero entries on the diagonal, it is invertible meaning that \(\vec{v}_{1},\dots, \vec{v}_{n}\) must also be a basis.
    🔗
    Suppose instead that \(\vec{v}_{1}, \dots, \vec{v}_{n}\) is an eigenbasis. Then for all \(1 \leq i \leq n\)
    \begin{equation*} Ae_{i} = P^{-1}TP(e_{i}) = P^{-1} T(\vec{v}_{i}) = P^{-1}(\lambda_{i}\vec{v}_{i}) = \lambda_{i} e_{i}\text{.} \end{equation*}
    Thus, \(A\) is diagonal.
    🔗
    🔗
    Intuitively, having a diagonal basis is helpful, but they carry even greater meaning. We’ll discuss applications of diagonalization next class and in the exercises. Unfortunately, not all operators are diagonalizable as you’ll show in one of the exercises. Our next steps are in pursuit of proving the following spooky theorem called the spectral theorem:
    🔗

    Theorem 1.5.

    Let \(A\) be an \(n \times n\) matrix such that \(A = A^{\intercal}\text{.}\) Then \(A\) is diagonalizable with real eigenvalues.
    🔗
    🔗
    🔗

    Subsection 1.5 Exercises

    We know how to take the square of a matrix. But how do we take the square root?
    🔗

    Checkpoint 1.6.

    Suppose that an \(n \times n\) matrix \(A\) is diagonalizable so \(A = P D P^{-1}\) and all of its eigenvalues are non-negative. Give an expression for \(\sqrt{A}\text{.}\)
    🔗
    🔗
    This is an important condition. Again like with numbers, not all matrices have real square roots.
    🔗

    Checkpoint 1.7.

    Show that the matrix
    \begin{equation*} A= \begin{pmatrix} 0 \amp 1 \\0 \amp 0\end{pmatrix} \end{equation*}
    is not diagonalizable andhas no square root.
    🔗
    🔗

    Checkpoint 1.8.

    Show that if an operator \(T: V \to V\) has \(n\) distinct eigenvalues and \(V\) is \(n\) dimensional, then \(V\) has an eigenbasis with respect to \(T\text{.}\)
    🔗
    🔗

    Checkpoint 1.9.

    Suppose that a matrix \(A\) is symmetric.
    🔗
    (a)
    Show that \(\langle \vec{u}, A\vec{v}\rangle = \langle A \vec{u},\vec{v}\rangle\text{,}\) where the inner product here is the regular old dot product.
    🔗
    🔗
    (b)
    Show that eigenvectors of a symmetric matrix with distinct eigenvalues are orthogonal.
