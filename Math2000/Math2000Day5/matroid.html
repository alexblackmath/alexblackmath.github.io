    Section 2 Spanning and Existence of Solutions

    One property the vectors
    \begin{equation*} \begin{pmatrix} 1\\0 \end{pmatrix} \text{ and } \begin{pmatrix} 0 \\1 \end{pmatrix} \end{equation*}
    have is that any two dimensional vector can be written as a linear combination of them. In notation,
    \begin{equation*} \text{span}\left( \begin{pmatrix} 1\\0 \end{pmatrix}, \begin{pmatrix} 0 \\1 \end{pmatrix}\right) = \mathbb{R}^{2}. \end{equation*}
    In other words, the linear equation with vector coefficients
    \begin{equation*} x\begin{pmatrix} 1 \\0\end{pmatrix} + y \begin{pmatrix} 0\\1 \end{pmatrix} = \begin{pmatrix} b_{1}\\b_{2} \end{pmatrix} \end{equation*}
    always has a solution. In matrix form
    \begin{equation*} \begin{pmatrix}1 \amp 0 \\0 \amp1 \end{pmatrix} \begin{pmatrix} x\\y \end{pmatrix} = \begin{pmatrix} b_{1} \\ b_{2} \end{pmatrix} \end{equation*}
    🔗
    We call such vectors spanning. Today, our first goal is to characterize when a set of vectors is spanning. It turns out by making those vectors the columns of a matrix \(A\text{,}\) this can be entirely determined from the matrix.
    🔗

    Theorem 2.1.

    A collection of \(n\) vectors in \(\mathbb{R}^{m}\) is spanning if in reduced row echelon form of the \(m \times n\) matrix with those columns as vectors has \(m\) pivot columns.
    🔗
    🔗
    For example, \(\begin{pmatrix} 1 \\0 \\0\end{pmatrix}\) and \(\begin{pmatrix} 1\\1\\ 0\end{pmatrix}\) are not spanning. If you put them as the columns of a matrix, you obtain
    \begin{equation*} \begin{pmatrix} 1 \amp 1 \\0 \amp1\\0 \amp0\end{pmatrix} \end{equation*}
    Doing replacement on the first row by subtracting the second yields the reduced row echelon form:
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \\0 \amp1\\0 \amp0\end{pmatrix} \end{equation*}
    There are only \(2\) pivot columns and the vectors have \(3\) entries, so they are not spanning.
    🔗
    The essential reason for this is the number of pivot columns is the number of rows with nonzero entries in reduced row echelon form. If there are fewer than \(m\) pivot columns, then the bottom row has to be a row of all \(0\)’s That means if the righthand side has a \(1\) in the last coordinate, you get the equation \(0 = 1\text{,}\) which has no solution.
    🔗
    Reinterpreting this in terms of spans, we find.
    🔗

    Theorem 2.2.

    If a collection of \(n\) vectors spans \(\mathbb{R}^{m}\text{,}\) then \(n \geq m\text{.}\)
    🔗
    🔗
    Why? This is because the matrix with them has at least \(m\) pivot columns, meaning it has to have at least \(m\) columns, and \(n\) is the number of columns. Therefore, \(n \geq m\text{.}\)
    🔗
    🔗

    Section 3 Independence and Uniqueness of Solutions

    Given a linear system of equations of the form \(A \vec{x} = \vec{b}\text{,}\) when is a solution unique?
    🔗
    We know from what we have shown so far, that this occurs, when the augmented matrix has no non-pivot columns except its last column in reduced row echelon form. In other words, if you just look at the coefficient matrix, you get the following:
    🔗

    Theorem 3.1.

    A linear system \(A \vec{x} = \vec{b}\) has a unique solution whenever one exists if and only if all columns of the reduced row echelon form of \(A\) are pivot columns.
    🔗
    🔗
    In that case, we say the columns of the matrix \(A\) are linearly independent. In particular, to relate to the definition, on the homework this means that \(A \vec{x} = \vec{0}\) has a unique solution \(\vec{x} = \vec{0}\text{.}\) Thus, any linear combination of the columns that equals \(\vec{0}\) has all \(0\) coefficients.
    🔗
    🔗

    Section 4 Rank-Nullity Theorem

    Arguably the most important result in linear algebra is captured by interpolating between these two cases. We define the rank of a matrix \(A\) to be the dimension of the span of its columns. For example, the following matrix is of rank \(2\text{:}\)
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp1 \\0\amp1\amp 1\\0 \amp 0 \amp0\end{pmatrix}. \end{equation*}
    This is because its columns span exactly the \(xy\)-plane.
    🔗
    We call the Nullity of a matrix the dimension of the solution set to \(A \vec{x} = \vec{0}\text{.}\) For example, consider the system
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp1 \\0\amp1\amp 1\\0 \amp 0 \amp0\end{pmatrix} \begin{pmatrix} x\\y\\z \end{pmatrix} = \begin{pmatrix} 0\\0\\0 \end{pmatrix}. \end{equation*}
    The augmented matrix is
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp1 \amp0\\0 \amp1 \amp1 \amp0\\0\amp 0 \amp0 \amp0 \end{pmatrix}, \end{equation*}
    which is in reduced row echelon form. It has one free variable, so the solution is \(1\) dimensional.
    🔗
    For this matrix, we can notice that the rank plus the nullity is always the number of columns of the matrix. This is true in general.
    🔗

    Theorem 4.1. Rank-Nullity Theorem.

    Let \(A\) be an \(m \times n\) matrix. Then the \(\text{rank}(A)\) is its number of pivot columns in reduced row echelon form and \(\text{Nullity}(A)\) is its number of non-pivot columns in reduced row echelon form. In particular, \(\text{rank}(A) + \text{Nullity}(A) = n\text{.}\)
    🔗
