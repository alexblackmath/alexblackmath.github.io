    Section 2 Reduced Row Echelon Form (RREF)

    We saw last in Exercise 5 that solving a linear system seems pretty doable when its coefficient matrix is diagonal such as this one:
    \begin{equation*} \begin{cases} 3x = 0\\ 2y = 8\\ 5z = 10 \end{cases} \end{equation*}
    🔗
    By rescaling we can force each coefficient on the left handside to be \(1\) and arrive at the following equation:
    \begin{equation*} \begin{cases} x = 0\\ y = 4\\ z = 2 \end{cases} \end{equation*}
    🔗
    The coefficient matrix of this equation has the following form
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 0\\ 0 \amp 1 \amp 0\\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    It is called the identity matrix. It is an ideal coefficient matrix. It turns out by applying row operations we can always arrive at a system with coefficient matrix that looks like the identity matrix. In fact, in general we will usually look at the augmented matrix. The shape is as follows:
    \begin{equation*} \begin{pmatrix} 1 \amp * \amp 0 \amp * \amp * \amp 0 \amp *\\ 0 \amp 0 \amp 1 \amp * \amp * \amp 0 \amp *\\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp * \end{pmatrix} \end{equation*}
    🔗
    An example linear system with such an augmented matrix would be the following:
    \begin{equation*} \begin{cases} x_{1} + x_{2} + x_{4} + x_{5} = 0\\ x_{3} - x_{4} - x_{5} = 12\\ x_{6} = 1 \end{cases} \end{equation*}
    🔗
    What you can see is that the solution is no longer unique. Now the variables \(x_{2}\text{,}\) \(x_{4}\text{,}\) and \(x_{5}\) can take on whatever value we choose, and \(x_{1}\text{,}\) \(x_{3}\text{,}\) and \(x_{6}\) are determined by those values.
    🔗
    A formal definition is as follows. We call the leftmost nonzero entry in a row of a matrix the leading entry of that row and call the column containing it the leading column of that row. A matrix is in Echelon Form if:
    🔗
    • All nonzero rows are above any rows of all zeros.
      🔗
      🔗
    • Each leading entry is in a column strictly to the right of the leading entry that comes before it.
      🔗
      🔗
    • All entries in a column below a leading entry are zeros.
      🔗
      🔗
    A matrix is in Reduced Row Echelon Form if in addition to the previous properties:
    🔗
    • The leading entry in each row is 1.
      🔗
      🔗
    • The leading entry is the only nonzero entry in its column.
      🔗
      🔗
    The columns containing leading entries are called pivot columns. I usually think of them as being dependent variables. The variables corresponding to the remaining columns are completely free to vary while the pivot columns are determined uniquely by their values. The number of free variables is the dimension of the set of solutions.
    🔗
    Take the system of equations in three variables:
    \begin{equation*} \begin{cases} x + z = 1\\ y + z = 1 \end{cases} \end{equation*}
    🔗
    The corresponding coefficient matrix is
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 1\\ 0 \amp 1 \amp 1 \end{pmatrix} \end{equation*}
    It is in reduced row echelon form. There is one free variable \(z\text{,}\) so the solution set is one dimensional. If we solve in terms of \(z\text{,}\) we get \(x=-z+1\text{,}\) \(y=-z+1\text{,}\) and of course \(z=z\text{.}\) If we parametrize the solution set in terms of \(z=t\text{,}\) we get the line
    \begin{equation*} f(t) = (-t+1,-t+1,t). \end{equation*}
    Geometrically this tells us the intersection of those two planes is that line. The free variable count told us without further computation that the solution set had to be one dimensional, and so it makes sense that it is a line.
    🔗
    🔗

    Section 3 Gaussian Elimination

    Theorem 3.1.

    By applying row operations, any matrix may be written in reduced row echelon form. Furthermore, the reduced row echelon form of that matrix is unique.
    🔗
    🔗
    The Gaussian Elimination algorithm goes as follows:
    🔗
    • Pick a row \(A_i\) with leftmost leading entry.
      🔗
      🔗
    • Scale that row so that its leading entry is \(1\text{.}\)
      🔗
      🔗
    • For each row \(A_j\) with the same leading column, replace it with \(A_j-\ell A_i\text{,}\) where \(\ell\) is the leading entry of \(A_j\text{.}\)
      🔗
      🔗
    • Apply interchange to move \(A_i\) to the top row.
      🔗
      🔗
    • Repeat on the submatrix consisting of all rows other than \(A_i\text{.}\)
      🔗
      🔗
    Let’s show this on an example. Consider the linear system:
    \begin{equation*} \begin{cases} 4x + 2y = 0\\ 2x = 4\\ y = 8 \end{cases} \end{equation*}
    🔗
    Start with the following matrix, which is the augmented matrix of the system:
    \begin{equation*} \begin{pmatrix} 4 \amp 2 \amp 0\\ 2 \amp 0 \amp 4\\ 0 \amp 1 \amp 8 \end{pmatrix} \end{equation*}
    🔗
    Pick a row with leftmost leading entry such as the second row. Rescale that row so its first entry is \(1\text{.}\)
    \begin{equation*} \begin{pmatrix} 4 \amp 2 \amp 0\\ 1 \amp 0 \amp 2\\ 0 \amp 1 \amp 8 \end{pmatrix} \end{equation*}
    🔗
    Then use it to cancel out the leading entry of any other row with the same leading entry by using replacement.
    \begin{equation*} \begin{pmatrix} 0 \amp 2 \amp -8\\ 1 \amp 0 \amp 2\\ 0 \amp 1 \amp 8 \end{pmatrix} \end{equation*}
    🔗
    Use interchange to place that row as the first row in the matrix.
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 2\\ 0 \amp 2 \amp -8\\ 0 \amp 1 \amp 8 \end{pmatrix} \end{equation*}
    🔗
    Then follow the same strategy on the remaining rows. The bottom row already has first nonzero entry equal to \(1\text{,}\) so we can take that one. We replace the second row with it minus twice the third row.
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 2\\ 0 \amp 0 \amp -24\\ 0 \amp 1 \amp 8 \end{pmatrix} \end{equation*}
    🔗
    Swap until row \(3\) is at the top of the rows not already sorted, so we swap it with row \(2\text{.}\)
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 2\\ 0 \amp 1 \amp 8\\ 0 \amp 0 \amp -24 \end{pmatrix} \end{equation*}
    🔗
    Then we have one more row. We rescale it to be \(1\text{.}\) Then we cancel out the entries in the columns for that row via replacement. In the end we get the identity matrix.
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 0\\ 0 \amp 1 \amp 0\\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    🔗
    Putting this back into equational form we get
    \begin{align*} x \amp= 0\\ y \amp= 0\\ 0 \amp= 1 \end{align*}
    Thus, the system has no solutions, since \(0\neq 1\text{.}\) In fact, the certification of there being no solution is an example of a more general phenomenon:
    🔗

    Theorem 3.2.

    A linear system is consistent if and only if the final column of the reduced row echelon form of its augmented matrix is not a pivot column.
    🔗
    🔗
    🔗

    Section 4 Parametrizing the Solution Set

    Let’s look back at this example.
    \begin{equation*} \begin{cases} x_{1} + x_{2} + x_{4} + x_{5} = 0\\ x_{3} - x_{4} - x_{5} = 12\\ x_{6} = 1 \end{cases} \end{equation*}
    🔗
    There are three free variables: \(x_{2}\text{,}\) \(x_{4}\text{,}\) and \(x_{5}\text{.}\) We can use those to parametrize our solution. In particular,
    \begin{align*} x_{1} \amp= -x_{2} - x_{4} - x_{5}\\ x_{3} \amp= x_{4} + x_{5} + 12\\ x_{6} \amp= 1 \end{align*}
    🔗
    Let \(x_{2}=a\text{,}\) \(x_{4}=b\text{,}\) and \(x_{5}=c\text{.}\) Then we get a \(3\)-D plane in \(\mathbb{R}^{6}\) with parametrization:
    \begin{equation*} f(a,b,c)=(-a-b-c,a,b+c+12,b,c,1). \end{equation*}
    🔗
    This is a plane. You can think of it parametrically as being of the form
    \begin{equation*} f(a,b,c) = a(-1,1,0,0,0,0) + b(0,0,1,1,0,0) + c(-1,0,1,0,1,0) + (0,0,12,0,0,1). \end{equation*}
    🔗
    Next time we will talk about this last formulation.
