The RREF Riders

Your Name, MAT 2000

1 Geometry Review

The main things we will need from vector calculus (Math 1800 at Bowdoin) and other prerequisites for this class are coming from 2-D and 3-D geometry. These problems review those topics.

Exercise 1

Consider the system of linear equations:

{ x+y=1 x−y=2 \\begin{cases}x+y=1\\x-y=2\\end{cases}
  • Is x=0 and y=1 a solution to the system? Explain why or why not.
  • Each of the two equations defines a line. Plot the two lines.
  • Is the system consistent or inconsistent? How many solutions does it have? Explain how your plot informs the answer.

Exercise 2

Consider the 3-variable equation:

x+y+z=1 x+y+z=1
  • Plot the solution set to this equation.
  • Write a parametric equation for this plane. That is, find the function f(x,y) such that the plane is the graph of z=f(x,y).

Exercise 3

Consider the following linear system of equations:

{ 2x−y=0 2y−z=0 \\begin{cases}2x-y=0\\2y-z=0\\end{cases}

Compute the cross product of (2,−1,0) and (0,2,−1). Is the result a solution to the system? Give a geometric reason for why you would expect your answer.

2 Equations and their Systems

Exercise 4

Consider the following system of equations:

{ x+y=5 2x+4y+z=9 3x+y+2z=10 \\begin{cases}x+y=5\\2x+4y+z=9\\3x+y+2z=10\\end{cases}
  1. Write the coefficient and augmented matrices of the system.
  2. Put the system in Reduced Row Echelon Form. Show the steps of your row reduction.
  3. Describe the set of all solutions to the system if it is consistent. Otherwise, explain why it is inconsistent.

Exercise 5

Consider the following augmented matrix of a linear system:

Augmented matrix with 3 rows and 4 columns
1230
4560
7890
  1. Write the system of equations associated with the augmented matrix.
  2. Put the system in Reduced Row Echelon Form. Show the steps of your row reduction.
  3. Describe the set of all solutions to the system if it is consistent. Otherwise, explain why it is inconsistent.

Exercise 6

Consider the following system:

x+2y+3z=0 x+2y+az=1 \\begin{aligned}x+2y+3z&=0\\x+2y+az&=1\\end{aligned}

Characterize the choices of a for which:

  1. The system has no solutions.
  2. The system has a unique solution.
  3. The system has infinitely many solutions.
