    Section 2 Transforming

    The core question of the day is: Which functions \(T: \mathbb{R}^{n} \to \mathbb{R}^{m}\) may be written as \(T(\vec{x}) = A \vec{x}\) for some \(m \times n\) matrix \(A\text{?}\)
    🔗
    What properties does this function have?
    🔗
    It is additive:
    🔗
    \begin{equation*} T(\vec{x} + \vec{y}) = A(\vec{x}+\vec{y}) = A\vec{x} + A\vec{y} = T(\vec{x}) + T(\vec{y}). \end{equation*}
    It respects scaling:
    🔗
    \begin{equation*} T(\lambda \vec{x}) = A(\lambda \vec{x}) = \lambda A\vec{x} = \lambda T(\vec{x}). \end{equation*}

    Definition 2.1.

    We call a function \(T: \mathbb{R}^{n} \to \mathbb{R}^{m}\) a linear transformation if \(T\) is additive and respects scaling.
    🔗
    🔗

    Theorem 2.2.

    A function \(T: \mathbb{R}^{n} \to \mathbb{R}^{m}\) is a linear transformation if and only if \(T(x) = Ax\) for some \(m \times n\) matrix \(A\text{.}\)
    🔗
    🔗
    Let’s start in one dimension. Then \(T: \mathbb{R} \to \mathbb{R}\text{.}\) A matrix in this setting corresponds to just multiplying by a number, so we want to show that \(T(x) = mx\) for some \(m \in \mathbb{R}\text{.}\)
    🔗
    Define \(m = T(1)\text{.}\) Then for all \(x \in \mathbb{R}\text{,}\)
    🔗
    \begin{equation*} T(x) = xT(1) = mx. \end{equation*}
    For higher dimensions, a similar argument works. Let \(T: \mathbb{R}^{2} \to \mathbb{R}\text{.}\) We would want to write this as
    🔗
    \begin{equation*} T(x,y) = \begin{pmatrix} m_{1} & m_{2} \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = m_{1} x + m_{2}y. \end{equation*}
    Define \(m_{1} = T(1,0)\) and \(m_{2} = T(0,1)\text{.}\) Then
    🔗
    \begin{equation*} T(x,y) = T(x(1,0) + y(0,1)) = xT(1,0) + y T(0,1) = m_{1} x+ m_{2}y. \end{equation*}
    It turns out this same argument works in general. We will just use some notation to make it work. Let \(\vec{e_{i}}\) be the vector \(1\) in the \(i\)th coordinate and zeroes otherwise.
    🔗
    Define \(T: \mathbb{R}^{n} \to \mathbb{R}^{m}\text{,}\) and suppose that \(T\) is a linear transformation. Then
    🔗
    \begin{equation*} \begin{aligned} T(x_{1},x_{2},\dots,x_{n}) &= T(\sum_{i=1}^{n} x_{i} e_{i}) \\ &= \sum_{i=1}^{n} x_{i}T(e_{i}) \\ &= \begin{pmatrix} T(e_{1}) & T(e_{2}) & \dots & T(e_{n}) \end{pmatrix} \begin{pmatrix} x_{1} \\ x_{2} \\ \vdots \\ x_{n} \end{pmatrix}. \end{aligned} \end{equation*}
    🔗

    Section 3 Exercises

    Checkpoint 3.1.

    Let \(T: \mathbb{R}^{3} \to \mathbb{R}^{2}\) be a linear transformation such that \(T(1,0,0) = (1,0)\text{,}\) \(T(0,1,0) = (0,1)\text{,}\) and \(T(0,0,1) = (1,1)\text{.}\) Write \(T\) in matrix form as \(T(\vec{x}) = A\vec{x}\text{.}\)
    🔗
    🔗

    Checkpoint 3.2.

    Write the linear transformation \(T: \mathbb{R}^{3} \to \mathbb{R}^{3}\) defined by \(T(x_{1}, x_{2}, x_{3}) = (x_{2},x_{3}, x_{1})\) as a matrix.
    🔗
    🔗

    Checkpoint 3.3.

    Explain why \(T: \mathbb{R}^{n} \to \mathbb{R}^{n-1}\) defined by \(T(x_{1},x_{2},\dots,x_{n}) = (x_{1},x_{2},\dots,x_{n-1})\) is a linear transformation. What is the matrix representation?
    🔗
    🔗

    Checkpoint 3.4.

    Explain why \(f(x,y) = xy\) is not a linear transformation.
    🔗
    🔗

    Checkpoint 3.5.

    Is \(f(x,y) = (-y,x)\) a linear transformation? If so, describe the matrix. If not, explain why not.
    🔗
    🔗

    Checkpoint 3.6.

    Is \(f(x,y) = \max(x,y)\) a linear transformation? If so, describe the matrix. If not, explain why not.
