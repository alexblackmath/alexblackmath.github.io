    Section 2 Matrix Representations

    Another crucial operation for vectors is the dot product
    \begin{equation*} \vec{x}\cdot \vec{y} = \sum_{i=1}^{n} x_{i}y_{i}. \end{equation*}
    For example, \((1,0,-1) \cdot (1,0,1) = 0\text{.}\)
    🔗
    Given a system of linear equations:
    \begin{align*} x + y \amp= 7,\\ y + z \amp= 9,\\ x+z \amp= 11 \end{align*}
    We can rewrite these equations using dot products with vectors,
    \begin{align*} (1,1,0) \cdot (x,y,z) \amp= 7\\ (0,1,1) \cdot (x,y,z) \amp= 9\\ (1,0,1) \cdot(x,y,z)\amp= 11 \end{align*}
    However, to save money and time on parentheses and rewriting \((x,y,z)\text{,}\) we just write this using the coefficient matrix as
    \begin{equation*} \begin{pmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp1 \\ 1 \amp 0 \amp1 \end{pmatrix} \begin{pmatrix} x\\ y\\ z \end{pmatrix} = \begin{pmatrix} 7 \\ 9\\ 11 \end{pmatrix}. \end{equation*}
    If we’re being really succinct, I call the coeffient matrix \(A\text{,}\) the variables \(\vec{x} =(x,y,z)\text{,}\) and the righthand side \(\vec{b} = (7,9,11)\text{.}\) Then we finally arrive at the standard way of writing down a system of linear equations
    \begin{equation*} A \vec{x} = \vec{b}. \end{equation*}
    In particular, given an \(m \times n\) matrix \(A\text{,}\) I can define its multiplication with a vector in \(\mathbb{R}^{n}\) by
    \begin{equation*} A \vec{x} = \begin{pmatrix} \vec{a}_{1} \\\vec{a}_{2} \\ \vdots \\\vec{a}_{m} \end{pmatrix} \vec{x} = \begin{pmatrix} \vec{a}_{1} \cdot \vec{x} \\\vec{a}_{2} \cdot \vec{x} \\ \vdots \\\vec{a}_{m} \cdot \vec{x} \end{pmatrix}. \end{equation*}
    For example,
    \begin{equation*} \begin{pmatrix} 0 \amp 1 \amp 0\\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\begin{pmatrix} 1 \\ 2 \\ 3\end{pmatrix} = \begin{pmatrix} 0(1) + 1(2) + 0(3) \\ 1(1) +0(2) + 0(3) \\0 (1) + 0(2) + 1(3) \end{pmatrix} = \begin{pmatrix} 2 \\ 1\\ 3 \end{pmatrix}. \end{equation*}
    🔗

    Theorem 2.1.

    Solving a system of linear equations corresponds to solving the matrix vector equation \(A \vec{x} = \vec{b}\text{,}\) where \(A\) is the coefficient matrix of the linear system and \(\vec{b}\) is the right hand side.

    Section 3 Two Ways to Represent a \(k\)-Dimensional Plane

    Consider the plane
    \begin{equation*} x+y+z = 0 \end{equation*}
    A parametric solution to the system is the following:
    \begin{equation*} f(y,z) = (-y-z,y,z) = y(-1,1,0) + z(-1,0,1). \end{equation*}
    In other words, the plane is \(\text{span}((-1,1,0), (-1,0,1))\text{.}\)
    🔗
    The first is an equational or outer representation. It tells you what the plane is by giving you a way to test by plugging it into the equation, but it does not give you a way to generate any vector in the plane without solving a linear system.
    🔗
    The second is a parametric or inner representation. This gives you an easy way to get vectors in the plane, but testing if a vector is in the plane corresponds to solving a linear system.
    🔗
    We’ve already covered how to go from an outer representation to an inner. That’s what Gaussian elimination does. But how does one go from an inner representation to an outer one?
    🔗
    In concrete terms: Given a collection of vectors, how do we find an equation describing their span?
    🔗
    This is where the dot product interpretation comes to help us. The key observation is: If a vector is in a row of our matrix representation it must dot product with each vector in the span to equal \(0\text{.}\) In other words, for \((-1,1,0)\) and \((-1,0,1)\) it must be a solution to the equation:
    \begin{equation*} \begin{pmatrix} -1 \amp 1 \amp 0 \\-1 \amp 0 \amp1 \end{pmatrix}\begin{pmatrix} x \\y\\z \end{pmatrix} = \begin{pmatrix} 0\\0 \end{pmatrix}. \end{equation*}
    We can solve this. The augmented matrix is
    \begin{equation*} \begin{pmatrix} -1 \amp 1 \amp 0 \amp 0 \\ -1 \amp0 \amp 1 \amp0\end{pmatrix}. \end{equation*}
    Replacing row \(1\) with row \(1\) - row \(2\) yields
    \begin{equation*} \begin{pmatrix} 0 \amp 1 \amp -1 \amp 0 \\ -1 \amp0 \amp 1 \amp0\end{pmatrix}. \end{equation*}
    Rescaling the second row by \(-1\) gives
    \begin{equation*} \begin{pmatrix} 0 \amp 1 \amp -1 \amp 0 \\ 1 \amp0 \amp -1 \amp0\end{pmatrix}. \end{equation*}
    Then interchanging yields the reduced row echelon form:
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp -1 \amp 0 \\ 0 \amp1 \amp -1 \amp0\end{pmatrix}. \end{equation*}
    The first two columns are pivot columns, and the equations are \(x-z= 0\) and \(y-z =0\text{.}\) Thus, the solution is \(f(z) = (z,z,z) = z(1,1,1)\text{,}\) so the solution set is \(\text{span}((1,1,1))\text{.}\)
    🔗
    It turns out then that \((1,1,1)\) is the row of the coefficient matrix in the equation defining \(\text{span}((-1,1,0), (-1,0,1))\) is defined by the matrix equation:
    \begin{equation*} \begin{pmatrix} 1 \amp 1 \amp1 \end{pmatrix}\begin{pmatrix} x\\y\\z \end{pmatrix} = 0. \end{equation*}
    In fact, that is how it always works. If you want to find an outer representation for the span of a set of vectors:
    • Put those vectors as rows of a matrix \(A\) in the equation \(A\vec{x} = \vec{0}\text{.}\)
      🔗
      🔗
    • Solve that equation.
      🔗
      🔗
    • Write that solution as a span of vectors.
      🔗
      🔗
    • Those vectors are the rows of the matrix \(B\) in the outer representation \(B \vec{x} = \vec{0}\text{.}\)
      🔗
      🔗
