    Section 1

    Subsection 1.1 Affine Span

    The affine span \(\text{aff}(S)\) of a set of vectors \(S\) is the set of all finite linear combinations of vectors in \(S\) such that the coefficients sum to \(1\text{.}\) Such a linear combination is called an affine linear combination. For example, \(2(1,0) + 3(0,1) + -4(1,1) = (2,3) -(4,4) = (-2,-1)\) is an affine combination of \((1,0), (0,1)\text{,}\) and \((1,1)\text{.}\)

    Subsection 1.2 Affine Independence

    A finite set of vectors is affinely independent if there is no nontrivial linear combination of them that sums to \(0\) such that the coefficients sum to \(0\text{.}\) For example \((0,2), (2,0), (1,1)\) are not affinely independent, because
    🔗
    \begin{equation*} 1(0,2) + 1(2,0) -2(1,1) = (0,0), \end{equation*}
    and \(1 + 1 -2 = 0\text{.}\)
