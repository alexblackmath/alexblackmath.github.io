    • What does it mean for a set of vectors to span a vector space?

    Checkpoint 1.1.

    Let \(\vec{v}_1,\dots,\vec{v}_k\in V\text{,}\) and suppose they are linearly independent. Let \(\vec{u}\in V\text{.}\) Then \(\vec{v}_1,\dots,\vec{v}_k,\vec{u}\) are linearly independent if and only if \(\vec{u}\notin\operatorname{span}(\vec{v}_1,\dots,\vec{v}_k)\text{.}\)

    Section 2 Bases

    A basis of a vector space \(V\) is a subset of \(V\) that is both linearly independent and spanning.
    🔗

    Theorem 2.1.

    Any vector space \(V\) of the form \(\operatorname{span}(S)\text{,}\) where \(S\) is finite, has a basis.
    🔗
    🔗

    Proof.
    Choose a linearly independent subset \(I\subseteq S\) of maximal cardinality; this is possible because \(S\) is finite. If \(I=S\text{,}\) then \(I\) is both spanning and linearly independent, so it is a basis.
    🔗
    Otherwise, let \(\vec{s}\in S\setminus I\text{.}\) Maximality of \(I\) implies that \(I\cup\{\vec{s}\}\) is linearly dependent. By Checkpoint 1.1, \(\vec{s}\in\operatorname{span}(I)\text{.}\) Thus every element of \(S\) lies in \(\operatorname{span}(I)\text{,}\) so
    🔗
    \begin{equation*} V=\operatorname{span}(S)\subseteq\operatorname{span}(I)\subseteq V. \end{equation*}
    Hence \(\operatorname{span}(I)=V\text{,}\) and \(I\) is a basis.
    🔗
    🔗

    Checkpoint 2.2.

    Which step used finiteness?
    🔗
    🔗
    A vector space that can be written as the span of finitely many vectors is called finite-dimensional. We call the size of a basis the dimension of a vector space. By the previous result, every finite-dimensional vector space has a finite basis, which is where the term comes from. However, this definition could hypothetically fail to make sense: if a vector space had one basis of size \(2\) and another of size \(3\text{,}\) what would its dimension be? Luckily, we can prove this cannot happen.
    🔗

    Theorem 2.3.

    Every basis of a finite-dimensional vector space has the same finite size.
    🔗
    🔗
    To prove this, we will use a famous lemma that gives a way to swap elements of bases.
    🔗

    Lemma 2.4. Steinitz Exchange Lemma.

    Let \(B_1\) and \(B_2\) be two bases of a finite-dimensional vector space. For any \(\vec{v}\in B_2\setminus B_1\text{,}\) there exists \(\vec{u}\in B_1\setminus B_2\) such that \((B_1\setminus\{\vec{u}\})\cup\{\vec{v}\}\) is a basis.
    🔗
    🔗

    Proof.
    Let \(\vec{v}\in B_2\setminus B_1\text{.}\) Since \(B_1\) is a basis, there are distinct vectors \(\vec{u}_1,\dots,\vec{u}_n\in B_1\) and scalars \(a_1,\dots,a_n\text{,}\) not all zero, such that
    🔗
    \begin{equation*} \vec{v}=\sum_{i=1}^{n}a_i\vec{u}_i. \end{equation*}
    Some \(\vec{u}_i\) with \(a_i\neq 0\) must lie in \(B_1\setminus B_2\text{.}\) Otherwise every \(\vec{u}_i\) with nonzero coefficient would lie in \(B_2\text{.}\) Since \(\vec{v}\notin B_1\text{,}\) the vector \(\vec{v}\) is distinct from all of these \(\vec{u}_i\text{,}\) and the displayed equation would give a nontrivial linear dependence among elements of \(B_2\text{.}\) Relabel if necessary so that \(a_n\neq 0\) and \(\vec{u}_n\in B_1\setminus B_2\text{.}\)
    🔗
    We claim that \((B_1\setminus\{\vec{u}_n\})\cup\{\vec{v}\}\) is a basis. First, it is linearly independent. Indeed, \(\vec{v}\notin\operatorname{span}(B_1\setminus\{\vec{u}_n\})\text{:}\) if it were, then \(\vec{v}\) would have an expression in the basis \(B_1\) with coefficient \(0\) on \(\vec{u}_n\text{,}\) contradicting uniqueness of basis coordinates since the displayed expression has \(a_n\neq 0\text{.}\) By Checkpoint 1.1, replacing \(\vec{u}_n\) by \(\vec{v}\) therefore preserves linear independence.
    🔗
    To show spanning, solve the displayed equation for \(\vec{u}_n\text{:}\)
    🔗
    \begin{equation*} \vec{u}_n=\frac{1}{a_n}\left(\vec{v}-\sum_{i=1}^{n-1}a_i\vec{u}_i\right). \end{equation*}
    Thus \(\vec{u}_n\in\operatorname{span}((B_1\setminus\{\vec{u}_n\})\cup\{\vec{v}\})\text{.}\) Every other element of \(B_1\) is already in the replacement set, so that set spans \(B_1\text{,}\) and hence spans \(V\text{.}\) Therefore \((B_1\setminus\{\vec{u}_n\})\cup\{\vec{v}\}\) is a basis.
    🔗
    🔗
    Using the exchange lemma, we can prove Theorem 2.3.
    🔗

    Proof of the basis-size theorem.
    Since the vector space is finite dimensional, it has a finite basis by the argument in the proof of Theorem 2.1. Let \(B_1\) and \(B_2\) be two bases, and suppose for the sake of contradiction that \(|B_1| < |B_2|\text{.}\) We may furthermore assume that \(B_1\) is finite.
    🔗
    Let \(S\) be a subset of \(B_{2} \setminus B_{1}\) of maximal size such that there exists \(T \subseteq B_{1} \setminus B_{2}\) such that \(|S| = |T|\) and \((B_{1} \setminus T) \cup S\) is a basis. Such a set exists, since one can take \(S = T = \emptyset\text{.}\) Note that
    🔗
    \begin{equation*} |(B_{1} \setminus T) \cup S| = |B_{1}| < |B_{2}|. \end{equation*}
    Thus, there exists \(\vec{v} \in B_{2} \setminus ((B_{1} \setminus T) \cup S)\text{.}\) Then by the Steinitz lemma, there exists \(\vec{u} \in (B_{1} \setminus T) \cup S\) such that \((B_{1} \setminus (T \cup \vec{u})) \cup S \cup \{\vec{v}\}\) is a basis, a contradiction to the maximality of \(S\text{.}\)
    🔗

    Section 3 Exercises

    Checkpoint 3.1.

    Apply Lemma 2.4 to \(B_1=\{(1,0,0),(0,1,0),(0,0,1)\}\) and \(B_2=\{(1,0,0),(1,1,0),(1,1,1)\}\) with \(\vec{v}=(1,1,0)\text{.}\)
    🔗
    🔗

    Checkpoint 3.2.

    Show that a set of vectors is spanning in a finite-dimensional vector space if and only if it contains a basis.
    🔗
    🔗

    Checkpoint 3.3.

    Show that a set of vectors is linearly independent in a finite-dimensional vector space if and only if it is contained in a basis.
    🔗
    🔗
    Some properties of bases break down if we use integer coefficients instead of coefficients from a field such as \(\mathbb{R}\text{.}\) Let \(\operatorname{span}_{\mathbb{Z}}(S)\) denote the set of integer linear combinations of elements of \(S\text{.}\) We call a set of vectors integer-linearly independent if the only integer linear combination of them that equals \(0\) is the trivial combination, in which all coefficients are zero.
    🔗

    Checkpoint 3.4.

    Let \(\mathbb{Z}\) denote the integers.
    🔗

    (a)

    Explain why \(\mathbb{Z}\neq\operatorname{span}_{\mathbb{Z}}\{2\}\) and \(\mathbb{Z}\neq\operatorname{span}_{\mathbb{Z}}\{3\}\text{.}\)
    🔗
    🔗

    (b)

    Show that \(\mathbb{Z}=\operatorname{span}_{\mathbb{Z}}\{2,3\}\text{.}\)
    🔗
    🔗

    (c)

    Show that a nontrivial integer linear combination of \(2\) and \(3\) equals \(0\text{.}\)
    🔗
    🔗
    Conclude that although \(\{2,3\}\) spans \(\mathbb{Z}\) over \(\mathbb{Z}\text{,}\) it contains no subset that both spans \(\mathbb{Z}\) over \(\mathbb{Z}\) and is integer-linearly independent.
