    Section 1 Random Variables Review

    A vector space of functions we care about are random variables, which are as Prof. Maresca likes to say, neither random nor variables. They are actually just functions \(X: S \to \mathbb{R}\) from some set \(S\) that has some probability space associated to it.
    🔗
    For example, the random variable could be the value on a \(6\)-sided die of a roll. Then \(X(i) = i\text{.}\)
    🔗
    The magic is that there is also a probability function \(P: S \to \mathbb{R}\) associated to the random variable telling you the probability of an outcome of the input to the random variable happening. For a die, we like to hope the probability function is just the constant function \(P(i) = 1/6\text{.}\) Probability functions satisfy the additional constraints that \(\sum_{s \in S} P(s) = 1\) and \(P(s) \geq 0\) for all \(s \in S\text{.}\)
    🔗
    🔗

    Section 2 Great Expectations

    Fix a probability space \(S\) and \(P: S \to [0,1]\) a density function. Then the set of random variables is just \(\mathbb{R}^{S}\text{,}\) the set of labelings of \(S\) be real-values. In particular, the set of random variables is a vector space. There is a very important map called the Expectation, which is
    🔗
    \begin{equation*} \mathbb{E}[X] = \sum_{s \in S} X(s) P(s). \end{equation*}

    Lemma 2.1 Linearity of Expectation.

    The function \(\mathbb{E}: \mathbb{R}^{S} \to \mathbb{R}\) is a linear transformation.
    🔗
    🔗

    Proof.
    Let \(X\) and \(Y\) be random variables, and let \(a \in \mathbb{R}\text{.}\) Then
    🔗
    \begin{equation*} \mathbb{E}[\lambda X] = \sum_{s\in S} \lambda X(s)P(s) = \lambda \sum_{s\in S}X(s)P(s) =\lambda \mathbb{E}[X], \end{equation*}
    and
    🔗
    \begin{align*} \mathbb{E}[X + Y] &= \sum_{s \in S} (X(s)+Y(s)) P(s)\\ &= \sum_{s \in S} X(s)P(s) + \sum_{s \in S} Y(s) P(s)\\ &=\mathbb{E}[X]+\mathbb{E}[Y]. \end{align*}
    🔗
    In fact, this extends more generally to infinite case using the same arguments but with infinite sums or more generally integrals. Expectation is one of the most useful linear transformations, and using linearity already buys you a lot.
    🔗
    🔗

    Section 3 Flipping Coins

    Here is a common quant interview style question. Suppose you flip a coin until you get heads. How many flips do you expect this to take?
    🔗
    Here the random variable is \(X(s)\) is the number of flips it takes to get heads. The probability space is infinite. Here we want essentially,
    🔗
    \begin{equation*} \sum_{i=1}^{\infty} i P(\text{First Heads after }i\text{ flips}). \end{equation*}
    You could compute this directly, or we could use linearity of expectation. You can compute this directly as an infinite series.
    🔗

    Checkpoint 3.1.

    Explain why the probability of the first heads appearing after \(i\) flips is \(1/2^{i}\text{.}\)
    🔗
    🔗
    Using the result of the exercise, you get the expectation
    🔗
    \begin{equation*} \sum_{i=1}^{\infty} i (1/2)^{i}, \end{equation*}
    and then you could use calculus tricks to compute it. But maybe you’re looking at that and don’t remember what a so-called “calculus” is. Instead you think there must be some better way. Indeed there is.
    🔗

    Theorem 3.2.

    The expected number of flips until reaching a first heads is \(2\text{.}\)
    🔗
    🔗

    Proof.
    You can split \(X\) into two random variables. Let \(Y\) be a variable that is \(1\) is you flip heads first and \(0\) otherwise. Let \(Z\) be a random variable that is \(0\) if you flip heads first and the number of flips until you reached your first heads otherwise.
    🔗
    Claim 1: \(X = Y + Z\text{.}\) The informal way to explain this is that \(X\) is the amount of time you wait until your first heads. If your first flip is a heads, \(X = 1\text{,}\) \(Y = 1\text{,}\) and \(Z = 0\) by definition. Hence, \(X = Y + Z\text{.}\) Otherwise, \(X\) is still the number of flips until the first heads, \(Y = 0\text{,}\) and \(Z\) is the number of flips until the first heads. Thus, \(X = Y + Z\) in both cases. Please feel free to use this kind of informal reasoning on the exercises.
    🔗
    Claim 2: \(\mathbb{E}[Y] = 1/2\text{.}\) This is direct, \(Y = 1\) if the first flip is heads, which happens with probability \(1/2\text{.}\) It is \(0\) otherwise, so the expected value is \(1(1/2) + 0 = 1/2\text{.}\)
    🔗
    Claim 3: \(\mathbb{E}[Z] = 1/2(\mathbb{E}[X]+1)\text{.}\) Note that \(Z\) is only nonzero with probability \(1/2\text{.}\) If \(Z\) is nonzero, the first flip is tails, and \(Z\) is the amount of time until reaching heads. The first flip being tails gives no information other than a flip has already occur. Thus, the expected amount of time after making the first flip until reaching heads is \(\mathbb{E}[X]\text{.}\) The expected overall number of flips is \(\mathbb{E}[X]+1\text{.}\) Since this case only arises with probability \(1/2\text{,}\) we obtain
    🔗
    \begin{equation*} \mathbb{E}[Z] = 1/2(\mathbb{E}[X]+1). \end{equation*}
    Finally, then putting this together,
    🔗
    \begin{align*} \mathbb{E}[X] &= \mathbb{E}[Y + Z]\\ &= \mathbb{E}[Y] + \mathbb{E}[Z]\\ &= 1/2 + 1/2(\mathbb{E}[X] +1). \end{align*}
    By subtract \(1/2\mathbb{E}[X]\) on both sides, this yields
    🔗
    \begin{equation*} \mathbb{E}[X]/2 = 1/2 + 1/2 = 1, \end{equation*}
    so \(\mathbb{E}[X] = 2\text{.}\)
    🔗
    🔗
    While it requires some thought, it is much easier to calculate and a better proof strategy to use this approach.
    🔗
    🔗

    Checkpoint 4.2.

    Find the expected number of coin flips until reaching the first consecutive pair of heads.
    🔗
    Solution.
    The result is \(6\text{.}\) We define four random variables. We let \(W\) be the number of flips until having the first consecutive pair of heads.
    🔗
    We let \(X\) be the random variable that is the number of flips until reaching the first consecutive pair of heads if the first flip is tails and \(0\) otherwise.
    🔗
    We let \(Y\) be the random variable that is \(2\) if the first two flips are heads and \(0\) otherwise.
    🔗
    We let \(Z\) be the random variable that is the number of flips until reaching the first two consecutive heads assuming the first two flips are HT.
    🔗
    Then, by construction, \(W = X+ Y+Z\text{,}\) because \(X\text{,}\) \(Y\text{,}\) and \(Z\) are only nonzero at disjoint times covering all of the cases. If the first flip is tails, by definition, only \(X\) is nonzero and gives the amount of time until the first two flips occurs which is \(W\text{.}\) Otherwise, the first flip is heads and there are two cases. If the second flip, is also heads, \(W = Y\) and the other variables are \(0\text{.}\) Otherwise, the second flip is tails, and we are in the \(Z\) case.
    🔗
    Therefore, \(W = X+Y+Z\text{.}\) Thus, we want to compute the expectations of each of these.
    🔗
    For \(X\text{,}\) this case occurs with probability \(1/2\text{,}\) since we know the start is tails. Then a flip has already occurred, but no other information is known. Thus, we get
    🔗
    \begin{equation*} \mathbb{E}[X] = 1/2(\mathbb{E}[W] + 1). \end{equation*}
    For \(Y\text{,}\) this case occurs with probability \(1/4\text{,}\) and we know for sure the out come is \(2\) flips, since the first two flips are heads. Thus,
    🔗
    \begin{equation*} \mathbb{E}[Y] = 1/4(2) = 1/2. \end{equation*}
    For \(Z\text{,}\) this case occurs with probability \(1/4\text{.}\) There are two initial flips, and otherwise, no information is gained. Thus, the resulting relation is
    🔗
    \begin{equation*} \mathbb{E}[Z] = 1/4(\mathbb{E}[W] + 2). \end{equation*}
    Then finally,
    🔗
    \begin{align*} \mathbb{E}[W] &= \mathbb{E}[X+Y+Z]\\ &= \mathbb{E}[X] + \mathbb{E}[Y] + \mathbb{E}[Z]\\ &= 1/2(\mathbb{E}[W] +1) + 1/2 + 1/4(\mathbb{E}[W] + 2)\\ &= 3/4\mathbb{E}[W] + 1/2 + 1/2 + 1/2\\ &= 3/4\mathbb{E}[W] + 3/2 \end{align*}
    Therefore, by subtracting \(3/4 \mathbb{E}[W]\) on both sides we get
    🔗
    \begin{equation*} \mathbb{E}[W]/4 = 3/2, \end{equation*}
    so \(\mathbb{E}[W] = 6\text{.}\) This coincides with what we saw in the simulations.
    🔗
    🔗
