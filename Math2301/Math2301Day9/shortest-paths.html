    The Path of Least Resistance

    🔗

    Section 1 Review

    Let \(W \subseteq \mathbb{R}^{n}\) be a linear subspace, and consider \(W_{\geq 0} = W \cap \mathbb{R}^{n}_{\geq 0}\text{.}\) An elementary vector \(\vec{w} \in W\) is a nonzero vector that is support minimal in the sense that there does not exist another nonzero vector \(\vec{u} \in W_{\geq 0}\) such that \(\text{supp}(\vec{u}) \subsetneq \text{supp}(\vec{w})\text{.}\)
    🔗

    Checkpoint 1.1.

    Let \(W \subseteq \mathbb{R}^{n}\) be a linear subspace and \(W_{\geq 0} = W \cap \mathbb{R}_{\geq 0}^{n}\text{.}\)
    🔗

    (a)

    Show that the support of any nonzero vector in \(W_{\geq 0}\) contains the support of some elementary vector.
    🔗
    🔗

    (b)

    Show that, for any nonzero vector \(\vec{v} \in W_{\geq 0}\text{,}\) there exists an elementary vector \(\vec{u} \in W_{\geq 0}\) such that \(\vec{v} - \vec{u} \in W_{\geq 0}\) and \(\text{supp}(\vec{v} - \vec{u}) \subsetneq \text{supp}(\vec{v})\text{.}\)
    🔗
    🔗

    (c)

    Show that \(W_{\geq 0}\) is the set of non-negative linear combinations of its elementary vectors.
    🔗

    Section 2 Shortest Paths

    Given a graph \(G = (N,E)\text{,}\) the shortest paths problem asks to find the shortest path between two nodes \(s\) and \(t\) of the graph, where the length of the path is the sum of the weights on the edges.
    🔗
    Our goal today is to model this problem using linear algebra.
    🔗

    Lemma 2.1.

    Let \(G = (N,E)\) be a directed graph with two distinguished nodes \(s, t \in N\) such that \((t,s) \in E\text{.}\) The support of any non-negative circulation \(\vec{w}\) on \(G\) for which \(\vec{w}_{(t,s)} > 0\) contains a path from \(s\) to \(t\text{.}\) As a consequence, the support of any minimal support circulation with \(\vec{w}_{(t,s)} > 0\) is a cycle containing \((t,s)\text{.}\)
    🔗
    🔗

    Proof.
    Any non-negative circulation is a non-negative combination of cycles. Thus, in particular, each edge in the support must be contained in such a cycle. Thus, \((t,s)\) is contained in a cycle meaning there is a path from \(s\) to \(t\) in the support. In particular, then a minimal support circulation must contain such a cycle and therefore the support must just be the cycle.
    🔗
    🔗
    We can define the cost of a non-negative circulation as
    \begin{equation*} c(\vec{w}) = \sum_{(u,v) \in E} \vec{w}_{(u,v)}\text{.} \end{equation*}
    The minimum cost circulation problem is to find a circulation of minimum cost subject to some constraints.
    🔗

    Theorem 2.2.

    Let \(G = (N,E)\) be a directed graph with two distinguished nodes \(s, t \in N\) such that \((t,s) \in E\text{.}\) The minimum cost of a non-negative circulation such that the weight on edge \((t,s)\) is \(1\) is \(1\) plus the minimal number of edges in a shortest path from \(s\) to \(t\text{.}\)
    🔗
    🔗

    Proof.
    Let \(\vec{w}\) be a non-negative circulation such that \(\vec{w}_{(t,s)} = 1\text{,}\) and suppose that \(\vec{w}\) is of minimal cost. Let \(C\) be any cycle containing \((t,s)\text{.}\) Then \(\chi_{C}\) is a non-negative circulation by last time, and \(\chi_{C}(t,s) = 1\text{.}\) Thus, \(\chi_{C}\) is a non-negative circulation with weight on edge \((t,s)\) equal to \(1\text{.}\) It follows that \(c(\chi_{C}) = |C|\text{.}\) Therefore, by minimality of \(\vec{w}\text{,}\) \(c(\vec{w}) \leq |C|\) meaning that \(c(\vec{w})\) is at most the minimum length of a cycle containing \((t,s)\text{.}\) It remains to show that it is exactly that.
    🔗
    Since \(\vec{w}\) is a non-negative circulation, by the main theorem of last class, it is a non-negative combination of indicator vectors of cycles. That is
    \begin{equation*} \vec{w} = \sum_{i=1}^{n} t_{i}\chi_{C_{i}}\text{,} \end{equation*}
    for some \(t_{i} > 0\) and cycles \(C_{i}\text{.}\)
    🔗
    Note that the cost of a non-negative circulation is the sum of its weights. This is a linear transformation, so
    \begin{equation*} c(\vec{w}) = \sum_{i=1}^{n} t_{i} c(\chi_{C_{i}}) = \sum_{i=1}^{n} t_{i} |C_{i}|\text{.} \end{equation*}
    From this expression, we can see that removing a cycle will only reduce the cost. Furthermore, removing any cycle preserves being a non-negative combination of cycles and thus being a non-negative circulation. The only property this could break would be that \(\vec{w}_{(t,s)} = 1\text{.}\)
    🔗
    If a cycle does not contain \((t,s)\text{,}\) then removing it preserves that \(\vec{w}_{(t,s)} = 1\text{.}\) Thus, by minimality of \(\vec{w}\text{,}\) we must have each \(C_{i}\) contains \((t,s)\text{.}\) Thus, \(\chi_{C_{i}}(t,s) = 1\) for all \(1 \leq i \leq n\text{,}\) so
    \begin{equation*} 1 = \vec{w}_{(t,s)} = \sum_{i=1}^{n} t_{i} \chi_{C_{i}}(t,s) = \sum_{i=1}^{n} t_{i}\text{.} \end{equation*}
    Let \(M\) be the minimal length of a cycle in the decomposition. Then
    \begin{equation*} c(\vec{w}) = \sum_{i=1}^{n} t_{i} |C_{i}| \geq \sum_{i=1}^{n} t_{i}M = M\sum_{i=1}^{n}t_{i} = M\text{.} \end{equation*}
    Thus, \(c(\vec{w})\) is at least the minimum length of a cycle containing \((t,s)\text{.}\)
    🔗
    Therefore, it is exactly the weight of a minimal cycle containing \((t,s)\text{,}\) which is the length of a shortest path plus \(1\text{.}\)
    🔗
    🔗
    This formulation of the shortest path problem endows it with geometry and allows us to use algorithms from linear algebra for solving it. This is particularly relevant right now with the proliferation of GPUs as problems represented in terms of linear algebra benefit from GPU based acceleration. For more details, you’ll have to take Math 3009 Combinatorial Optimization.
    🔗

    Section 3 Exercises

    Checkpoint 3.1.

    Let \(G = (N,E)\) be a weighted graph with distinguished vertices \(s\) and \(t\) and edge \((t,s)\text{.}\) Let \(\vec{c} \in \mathbb{R}^{E}\text{.}\) Define the weighted cost of a circulation as
    \begin{equation*} \vec{c} \cdot \vec{w} = \sum_{(u,v) \in E} c_{(u,v)}w_{(u,v)}\text{.} \end{equation*}
    Suppose that \(\vec{c}\) is non-negative and \(c_{(t,s)} =0\text{.}\) Then the minimum cost of a non-negative weighted circulation \(\vec{w}\) such that \(\vec{w}_{(s,t)} \neq 0\) is the minimum length of a weighted shortest path with edge weights \(\vec{c}\text{.}\)
