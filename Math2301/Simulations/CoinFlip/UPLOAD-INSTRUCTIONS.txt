COIN FLIP SIMULATION — DROP-IN FOR AN EXISTING GITHUB PAGES SITE

1. Upload this entire folder named "coin-flip-simulation" to the root of your existing GitHub Pages repository.

2. Do NOT replace your existing site's index.html. This folder has its own index.html and is isolated from the rest of your site.

3. Commit/publish the files as usual.

4. Open the simulation at:
   https://YOUR-SITE/coin-flip-simulation/

   Examples:
   User/organization site:
   https://username.github.io/coin-flip-simulation/

   Project site:
   https://username.github.io/repository-name/coin-flip-simulation/

5. To link to it from an existing page, use a relative link such as:
   <a href="coin-flip-simulation/">Coin Flip Simulation</a>

   If the page containing the link is in a subfolder, adjust the relative path as you normally would.

No build process, package manager, CDN, or external library is required.
All navigation, CSS, and JavaScript paths inside the simulation are relative.
