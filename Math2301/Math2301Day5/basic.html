    Section 2 Finishing Bases

    Theorem 2.1.

    Every basis of a finite dimensional vector space has the same size.
    🔗
    🔗

    Proof of Theorem 2.1.
    Let \(B_{1}\) and \(B_{2}\) be two bases, and suppose for the sake of contradiction that \(|B_{1}| \lt |B_{2}|\text{.}\) Let \(S\) be a subset of \(B_{2} \setminus B_{1}\) of maximal size such that there exists \(T \subseteq B_{1} \setminus B_{2}\) such that \(|S| = |T|\) and \((B_{1} \setminus T) \cup S\) is a basis. Such a set exists, since one can take \(S = \emptyset\text{.}\) Note that
    🔗
    \begin{equation*} |(B_{1} \setminus T) \cup S| = |B_{1}| \lt |B_{2}|. \end{equation*}
    🔗
    Thus, there exists \(\vec{v} \in B_{2} \setminus ((B_{1} \setminus T) \cup S)\text{.}\) Then by the Steinitz lemma, there exists \(\vec{u} \in ((B_{1} \setminus T) \cup S) \setminus B_{2}\) such that \((B_{1} \setminus (T \cup \vec{u})) \cup S \cup \{\vec{v}\}\) is a basis, a contradiction to the maximality of \(S\text{.}\)
    🔗
    🔗

    Section 3 Linear Transformations

    We have talked about vector spaces and now know that vector spaces have bases. Part of the purpose of bases is they give you a way to identify vector spaces and move between them.
    🔗

    Definition 3.1.

    A linear transformation \(T: V \to W\text{,}\) where \(V\) and \(W\) are vector spaces, is a function such that for any \(\vec{u}, \vec{v} \in V\) and \(\lambda \in \mathbb{R}\text{,}\) \(T(\vec{u} + \vec{v}) = T(\vec{u}) + T(\vec{v})\) and \(T(\lambda \vec{u}) = \lambda T(\vec{u})\text{.}\)
    🔗
    🔗
    That is, a linear transformation is a function that preserves the only two things we are guaranteed to be able to do in a vector space, scaling and adding.
    🔗

    Example 3.2.

    Any map of the form \(T: \mathbb{R}^{n} \to \mathbb{R}^{m}\) given by \(T(\vec{x}) = A \vec{x}\) for \(A\) an \(m \times n\) matrix is a linear transformation.
    🔗
    🔗

    Example 3.3.

    The map \(\text{ev}_{1}\) from the set of real valued functions to numbers given by \(\text{ev}_{1}(f) = f(1)\) is a linear transformation.
    🔗
    🔗

    Example 3.4.

    The map \(\frac{d}{dx}\) from differentiable functions to functions is a linear transformation, since
    🔗
    \begin{equation*} \frac{d}{dx}(f(x) + g(x)) = \frac{df}{dx}(x) + \frac{dg}{dx}(x) \text{ and } \frac{d}{dx}\lambda f(x) = \lambda \frac{d}{dx}f(x). \end{equation*}
    🔗
    🔗
    Once you know a function is a linear transformation, you learn some important properties of it for free.
    🔗

    Theorem 3.5.

    Let \(T: V \to W\) be a linear transformation between two vector spaces \(V\) and \(W\text{.}\) Then \(T(\vec{0}_{V}) =\vec{0}_{W}\text{.}\)
    🔗
    🔗

    Proof.
    Note that \(T(\vec{0}_{V}) = T(0(\vec{0}_{V})) = 0 T(\vec{0}_{V}) = \vec{0}_{W}.\)
    🔗
    🔗
    For example, the derivative of the \(0\) function is \(0\text{,}\) and multiplying a matrix by the zero vector always yields \(\vec{0}\text{.}\) This is a uniform proof of both phenomena.
    🔗
    In fact, a stronger statement is true. For any linear transformation \(T: V \to W\text{,}\) we define \(\ker(T) = \{\vec{x} \in V: T(\vec{x}) =\vec{0}_{W}\}\text{,}\) the pre-image of \(\vec{0}_{W}\text{.}\) We just showed that \(\vec{0}_{V} \in \ker(T)\text{.}\) Recall that is one of the three properties for being a linear subspace.
    🔗

    Theorem 3.6.

    For any linear transformation \(T:V \to W\text{,}\) \(\ker(T)\) is a linear subspace of \(V\text{.}\)
    🔗
    🔗

    Proof.
    We just showed \(\vec{0}_{V} \in \ker(T)\text{.}\) Thus, it suffices to show closure under addition and scalar multiplication. Let \(\vec{x}, \vec{y} \in \ker(T)\text{.}\) Then
    🔗
    \begin{equation*} T(\vec{x} + \vec{y}) = T(\vec{x}) + T(\vec{y}) = \vec{0}_{W} + \vec{0}_{W} = \vec{0}_{W}. \end{equation*}
    🔗
    Let \(\lambda \in \mathbb{R}\text{.}\) Then
    🔗
    \begin{equation*} T(\lambda \vec{x}) = \lambda T(\vec{x}) = \lambda\vec{0}_{W} = \vec{0}_{W}. \end{equation*}
    🔗
    Thus, \(\vec{x}+\vec{y}, \lambda \vec{x} \in \ker(T)\text{.}\) Therefore, by definition, \(\ker(T)\) is a linear subspace.
    🔗
    🔗
    This fact gives a very useful way to build various linear subspaces. For example, this shows that functions with derivative \(0\) are a linear subspace. These are exactly the constant functions, which indeed are preserved under scaling and addition. It also shows that for any \(m \times n\) matrix, the set of \(\vec{x} \in \mathbb{R}^{n}\) such that
    🔗
    \begin{equation*} A\vec{x} = \vec{0} \end{equation*}
    🔗
    is always a linear subspace. The power of this general statement is we get a proof of both facts simultaneously all as a consequence of this fundamental idea.
    🔗
    Kernels also tell us about a linear transformation. Recall from 2020 that a function \(f\) is one-to-one if each input has a distinct output. That is \(f(x) = f(y)\) implies \(x = y\text{.}\)
    🔗

    Theorem 3.7.

    Let \(T:V \to W\) be a linear transformation between vector spaces \(V\) and \(W\text{.}\) Then \(T\) is one-to-one if and only if \(\ker(T) = \{\vec{0}_{V}\}\text{.}\)
    🔗
    🔗

    Proof.
    (\(\Longrightarrow\)) Suppose that \(T\) is one-to-one. Note that \(T(\vec{0}_{V}) = \vec{0}_{W}\text{.}\) Since \(T\) is one-to-one, \(\vec{0}_{V}\) is the only vector for which that is the case. Therefore, \(\ker(T) = \{\vec{0}_{V}\}\text{.}\)
    🔗
    (\(\Longleftarrow\)) Suppose that \(\ker(T) = \{\vec{0}_{V}\}\text{.}\) Let \(\vec{u}, \vec{v} \in V\text{,}\) and suppose that \(T(\vec{u}) =T(\vec{v})\text{.}\) To prove \(T\) is one-to-one, we want to then show that \(\vec{u} = \vec{v}\text{.}\) To argue this, observe that
    🔗
    \begin{equation*} T(\vec{u}-\vec{v}) = T(\vec{u}) - T(\vec{v}) = \vec{0}_{W}. \end{equation*}
    🔗
    Thus, \(\vec{u} - \vec{v} \in \ker(T)\text{.}\) Therefore, since \(\ker(T) = \{\vec{0}_{V}\}\text{,}\) \(\vec{u} - \vec{v} = \vec{0}_{V}\text{,}\) so \(\vec{u} = \vec{v}\text{.}\) Therefore, \(T\) is one-to-one.
    🔗
    🔗
    Linear transformations give rise to another set called their image denoted
    🔗
    \begin{equation*} \text{Im}(T) = \{T(\vec{x}): \vec{x} \in V\}. \end{equation*}
    🔗

    Theorem 3.8.

    Let \(T: V \to W\) be a linear transformation from a vector space \(V\) to a vector space \(W\text{.}\) Then \(\text{Im}(T)\) is a linear subspace of \(W\text{.}\)
    🔗
    🔗

    Proof.
    Note that \(\vec{0}_{W} = T(\vec{0}_{V}) \in \text{Im}(T)\text{.}\) Thus, the image contains the zero vector.
    🔗
    Let \(\vec{x}, \vec{y} \in \text{Im}(T)\text{.}\) Then there exist \(\vec{u}, \vec{v} \in V\) such that \(T(\vec{u}) = \vec{x}\) and \(T(\vec{v}) = \vec{y}\text{.}\) It follows that
    🔗
    \begin{equation*} \vec{x} + \vec{y} = T(\vec{u}) + T(\vec{v}) = T(\vec{u} + \vec{v}) \in \text{Im}(T). \end{equation*}
    🔗
    Therefore, \(\text{Im}(T)\) is closed under addition.
    🔗
    Let \(\lambda \in \mathbb{R}\text{.}\) Then
    🔗
    \begin{equation*} \lambda \vec{x} = \lambda T(\vec{u}) = T(\lambda \vec{u}) \in \text{Im}(T). \end{equation*}
    🔗
    Therefore, \(\text{Im}(T)\) is closed under scalar multiplication and is thus a linear subspace.
    🔗
    🔗

    Section 4 Exercises

    Recall that a function \(T: V \to W\) is called onto if its range is \(W\text{.}\)
    🔗

    Checkpoint 4.1.

    Explain why for a linear transformation \(T: V \to W\) between vector spaces \(V\) and \(W\text{,}\) \(\text{Im}(T) = W\) if and only if \(T\) is onto.
    🔗
    🔗
    Part of the purpose of the introduction of kernel and images is to give you new ways to build linear subspaces.
    🔗

    Checkpoint 4.2.

    Let \(S\) denote the set of vectors \((x,y) \in \mathbb{R}^{2}\) such that \(x = y\text{.}\) Is \(S\) a linear subspace? If yes, find a linear transformation \(T: \mathbb{R}^{2} \to \mathbb{R}^{2}\) for which \(S = \ker(T)\text{.}\) Otherwise, prove why not.
    🔗
    🔗

    Checkpoint 4.3.

    Let \(S\) denote the set of vectors \((x,y) \in \mathbb{R}^{2}\) such that \(x = y +1\text{.}\) Is \(S\) a linear subspace? If yes, find a linear transformation \(T: \mathbb{R}^{2} \to \mathbb{R}^{2}\) for which \(S = \ker(T)\text{.}\) Otherwise, prove why not.
    🔗
    🔗

    Checkpoint 4.4.

    Prove that the set of functions that are their own derivative is a linear subspace.
    🔗
    🔗

    Checkpoint 4.5.

    Let \(T: U \to V\) and \(T': V\to W\) be linear transformations between vector spaces. Show that \(\text{Im}(T) \subseteq \ker(T')\) if and only if \(T' \circ T:U \to W\) is the \(0\)-function.
