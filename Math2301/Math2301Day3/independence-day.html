    Section 2 Independence

    Last time, we showed that for a vector space \(U\text{,}\) \(\operatorname{span}(U)=U\text{.}\) We can often find a much smaller subset \(S\subseteq U\) such that \(\operatorname{span}(S)=U\text{.}\) Such a subset is called a spanning subset of \(U\text{.}\)
    🔗
    For example, consider the \(xy\)-plane:
    \begin{equation*} \{(x,y,0):x,y\in\mathbb{R}\}. \end{equation*}
    🔗
    We can rewrite it as
    \begin{equation*} \{x(1,0,0)+y(0,1,0):x,y\in\mathbb{R}\}=\operatorname{span}\{(1,0,0),(0,1,0)\}. \end{equation*}
    🔗
    Thus, even though the \(xy\)-plane consists of infinitely many vectors, we need only two vectors to span it.
    🔗
    If we remove either of these two vectors, the span changes. In particular, the following three subspaces are distinct:
    \begin{equation*} \operatorname{span}\{(1,0,0)\},\qquad\operatorname{span}\{(0,1,0)\},\qquad\operatorname{span}\{(1,0,0),(0,1,0)\}. \end{equation*}
    🔗
    The first is the \(x\)-axis, the second is the \(y\)-axis, and the third is the \(xy\)-plane. Thus, this spanning set is minimal in the sense that its span changes if we remove any vector.
    🔗
    We call a set \(S\) of vectors linearly independent if \(\operatorname{span}(T)\neq\operatorname{span}(S)\) for every proper subset \(T\subsetneq S\text{.}\) We use the convention
    \begin{equation*} \operatorname{span}(\emptyset)=\{\vec{0}\}. \end{equation*}
    🔗
    In particular, the empty set is linearly independent, whereas \(\{\vec{0}\}\) is not. A set that is not linearly independent is called linearly dependent. Another example of a linearly dependent set is
    \begin{equation*} \{(1,0,0),(0,1,0),(1,1,0)\}, \end{equation*}
    🔗
    since
    \begin{equation*} \operatorname{span}\{(1,0,0),(0,1,0),(1,1,0)\}=\operatorname{span}\{(1,0,0),(0,1,0)\}. \end{equation*}
    🔗
    Linear independence is often defined using the equivalent criterion in the following theorem.
    🔗

    Theorem 2.1.

    Let \(V\) be a vector space, and let \(S=\{\vec{v}_1,\dots,\vec{v}_n\}\subseteq V\) be a finite set of distinct vectors, where \(n\geq 1\text{.}\) Then \(S\) is linearly independent if and only if the only scalars \(a_1,\dots,a_n\in\mathbb{R}\) satisfying
    \begin{equation*} \sum_{i=1}^{n}a_i\vec{v}_i=\vec{0} \end{equation*}
    🔗
    are \(a_1=\cdots=a_n=0\text{.}\)
    🔗
    🔗

    Proof.
    We prove both directions.
    🔗
    \((\implies)\) Suppose that \(S\) is linearly independent. Assume, for a contradiction, that
    \begin{equation*} \sum_{i=1}^{n}a_i\vec{v}_i=\vec{0} \end{equation*}
    🔗
    for scalars that are not all zero. Choose \(k\) such that \(a_k\neq 0\text{.}\) Rearranging and dividing by \(a_k\) gives
    \begin{equation*} \vec{v}_k=-\sum_{\substack{1\leq i\leq n\\i\neq k}}\frac{a_i}{a_k}\vec{v}_i. \end{equation*}
    🔗
    Thus \(\vec{v}_k\in\operatorname{span}(S\setminus\{\vec{v}_k\})\text{,}\) so
    \begin{equation*} \operatorname{span}(S)=\operatorname{span}(S\setminus\{\vec{v}_k\}). \end{equation*}
    🔗
    This contradicts linear independence. The argument also covers \(n=1\text{:}\) in that case, the sum on the right is empty and equals \(\vec{0}\text{.}\)
    🔗
    \((\impliedby)\) To do this, we prove the contrapositive statement. Suppose that \(S\) is linearly dependent. Then there is a proper subset \(T\subsetneq S\) such that \(\operatorname{span}(T)=\operatorname{span}(S)\text{.}\) Since \(T \subsetneq S\) there exists \(\vec{v}_k\in S\setminus T\text{.}\) Since
    \begin{equation*} T\subseteq S\setminus\{\vec{v}_k\}\subseteq S, \end{equation*}
    🔗
    \begin{equation*} \operatorname{span}(T)\subseteq\operatorname{span}(S\setminus\{\vec{v}_k\})\subseteq\operatorname{span}(S). \end{equation*}
    🔗
    The first and last spans are equal, so all three are equal. In particular, \(\vec{v}_k\) lies in the span of the remaining vectors. Hence there are scalars \(b_i \in\mathbb{R}\) for each \(i \neq k \) such that
    \begin{equation*} \vec{v}_k=\sum_{\substack{1\leq i\leq n\\i\neq k}}b_i\vec{v}_i. \end{equation*}
    🔗
    Setting \(b_k=-1\) yields
    \begin{equation*} \sum_{i=1}^{n}b_i\vec{v}_i=\vec{0}. \end{equation*}
    🔗
    Because \(b_k=-1\neq 0\text{,}\) the coefficients are not all zero. Thus, we have shown if the set is linearly dependent, then there is a nontrivial linear combination equal to \(0 \text{,}\) which is the contrapositive of the original statement.
    🔗
    🔗
    Given a vector space, we will define the dimension to be the minimal number of vectors in any spanning set. We will need to do some more work to explain why that definition makes sense and will continue with that next time.
    🔗

    Theorem 2.2.

    Let \(V\) be a vector space, and let \(S \subseteq V\) be a linearly independent subset of \(V\text{.}\) Then for any \(\vec{x} \in V \setminus \operatorname{span}(S)\text{,}\) \(S \cup \{x\} \) is linearly independent.
    🔗
    🔗

    Proof.
    Suppose not. Then there exists a linearly independent set \(S \subseteq V \) and \(\vec{x} \in V \setminus \operatorname{span}(S) \) such that \(S \cup \{x\} \) is linearly dependent. Then in particular, there exist \(\vec{v}_{1}, \dots, \vec{v}_{k} \in S \) and \(a_{1}, \dots, a_{k}, a_{k+1} \in \mathbb{R}\) not all zero such that
    🔗
    \begin{equation*} a_{k+1} \vec{x} + \sum_{i=1}^{k} a_{i} \vec{v}_{i} = \vec{0}. \end{equation*}
    🔗
    Since \(\vec{v}_{1}, \dots, \vec{v}_{k}\) are linearly independent, one cannot have \(a_{k+1} = 0\text{.}\) Thus, by moving everything other than \(\vec{x} \) to one side, we find that
    🔗
    \begin{equation*} a_{k+1} \vec{x} = -\sum_{i=1}^{k} a_{i} \vec{v}_{i} \end{equation*}
    🔗
    Since \(a_{k+1} \neq 0\text{,}\) we may divide by it on both sides to find
    🔗
    \begin{equation*} \vec{x} = \sum_{i=1}^{k} \frac{a_{i}}{a_{k+1}} \vec{v}_{i} \end{equation*}
    🔗
    But then, by definition, \(\vec{x} \in \operatorname{span}(\vec{v}_{1}, \dots, \vec{v}_{k}) \subseteq \operatorname{span}(S)\text{.}\)
    🔗
    🔗

    • \(\{\vec{0}\}\) in a real vector space \(V\text{.}\)
      🔗
      🔗
    • \(\{(1,0),(0,1)\}\) in \(\mathbb{R}^2\text{.}\)
      🔗
      🔗
    • \(\{(1,-1,0),(1,0,-1),(0,1,-1)\}\) in \(\mathbb{R}^3\text{.}\)
      🔗
      🔗

      🔗
