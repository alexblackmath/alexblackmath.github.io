Theorem 2.1.

Any vector space \(V\) of the form \(\operatorname{span}(S)\text{,}\) where \(S\) is finite, has a basis.
🔗
🔗

Proof.
Choose a linearly independent subset \(I\subseteq S\) of maximal cardinality; this is possible because \(S\) is finite. If \(I=S\text{,}\) then \(I\) is both spanning and linearly independent, so it is a basis.
🔗
Otherwise, let \(\vec{s}\in S\setminus I\text{.}\) Maximality of \(I\) implies that \(I\cup\{\vec{s}\}\) is linearly dependent. By Checkpoint 1.1, \(\vec{s}\in\operatorname{span}(I)\text{.}\) Thus every element of \(S\) lies in \(\operatorname{span}(I)\text{,}\) so
🔗
\begin{equation*} V=\operatorname{span}(S)\subseteq\operatorname{span}(I)\subseteq V. \end{equation*}
Hence \(\operatorname{span}(I)=V\text{,}\) and \(I\) is a basis.
