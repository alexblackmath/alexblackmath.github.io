Lemma 2.4. Steinitz Exchange Lemma.

Let \(B_1\) and \(B_2\) be two bases of a finite-dimensional vector space. For any \(\vec{v}\in B_2\setminus B_1\text{,}\) there exists \(\vec{u}\in B_1\setminus B_2\) such that \((B_1\setminus\{\vec{u}\})\cup\{\vec{v}\}\) is a basis.
🔗
🔗

Proof.
Let \(\vec{v}\in B_2\setminus B_1\text{.}\) Since \(B_1\) is a basis, there are distinct vectors \(\vec{u}_1,\dots,\vec{u}_n\in B_1\) and scalars \(a_1,\dots,a_n\text{,}\) not all zero, such that
🔗
\begin{equation*} \vec{v}=\sum_{i=1}^{n}a_i\vec{u}_i. \end{equation*}
Some \(\vec{u}_i\) with \(a_i\neq 0\) must lie in \(B_1\setminus B_2\text{.}\) Otherwise every \(\vec{u}_i\) with nonzero coefficient would lie in \(B_2\text{.}\) Since \(\vec{v}\notin B_1\text{,}\) the vector \(\vec{v}\) is distinct from all of these \(\vec{u}_i\text{,}\) and the displayed equation would give a nontrivial linear dependence among elements of \(B_2\text{.}\) Relabel if necessary so that \(a_n\neq 0\) and \(\vec{u}_n\in B_1\setminus B_2\text{.}\)
🔗
We claim that \((B_1\setminus\{\vec{u}_n\})\cup\{\vec{v}\}\) is a basis. First, it is linearly independent. Indeed, \(\vec{v}\notin\operatorname{span}(B_1\setminus\{\vec{u}_n\})\text{:}\) if it were, then \(\vec{v}\) would have an expression in the basis \(B_1\) with coefficient \(0\) on \(\vec{u}_n\text{,}\) contradicting uniqueness of basis coordinates since the displayed expression has \(a_n\neq 0\text{.}\) By Checkpoint 1.1, replacing \(\vec{u}_n\) by \(\vec{v}\) therefore preserves linear independence.
🔗
To show spanning, solve the displayed equation for \(\vec{u}_n\text{:}\)
🔗
\begin{equation*} \vec{u}_n=\frac{1}{a_n}\left(\vec{v}-\sum_{i=1}^{n-1}a_i\vec{u}_i\right). \end{equation*}
Thus \(\vec{u}_n\in\operatorname{span}((B_1\setminus\{\vec{u}_n\})\cup\{\vec{v}\})\text{.}\) Every other element of \(B_1\) is already in the replacement set, so that set spans \(B_1\text{,}\) and hence spans \(V\text{.}\) Therefore \((B_1\setminus\{\vec{u}_n\})\cup\{\vec{v}\}\) is a basis.
